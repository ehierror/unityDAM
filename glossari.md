GameObject: cualquier objeto que existe dentro de una escena, como un personaje, una cámara o una pared.
Component: elemento que se añade a un GameObject para darle propiedades o funcionalidades, como físicas o sonido.
Transform: componente que define la posición, la rotación y la escala de un objeto.
Prefab: plantilla reutilizable que permite crear varias copias de un objeto con la misma configuración.
Script: archivo de código, normalmente escrito en C#, que permite programar el comportamiento de los objetos.
Rigidbody: componente que permite que un objeto participe en el sistema de físicas de Unity, por ejemplo, para que caiga por la gravedad.
Collider: componente que define una forma para detectar colisiones entre objetos.
Asset: cualquier recurso que se utiliza en un proyecto, como modelos 3D, imágenes, sonidos, materiales o scripts.
Hierarchy: ventana que muestra todos los GameObjects que hay en la escena actual y su relación entre ellos.
Scene View: ventana del editor que permite visualizar y modificar los objetos de una escena desde distintas perspectivas.
